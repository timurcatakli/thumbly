---
title: Requirements
description: What you need before installing Thumbly.
---

| You need | Details |
| --- | --- |
| Mac | macOS 14 Sonoma or later. |
| iPhone | iOS 17.4 or later. Check in **Settings → General → About**. |
| Cable | A USB data cable. Some charging-only cables do not carry data. |
| Command Line Tools | Apple's Xcode Command Line Tools, used to build the Thumbly app. The installer tells you if they are missing; install them with `xcode-select --install`. |
| Internet | Needed to download Thumbly, and once so Thumbly can install Apple's developer disk image on the phone. |
| Passcode | You unlock the iPhone and confirm Trust and Developer Mode during setup. |

Thumbly runs under your macOS user account. Whoever uses that account on the Mac is the owner: they approve AI clients and can pause phone control in the Thumbly app.
